# LearnEnglish Bot 🇬🇧

Телеграм-бот, который ведёт от A2 к B1: слова с интервальным повторением, грамматика под личные слабые места,
аудирование, квесты за очки, проверки знаний и напоминания. Всё обёрнуто в XP, уровни, стрики, ачивки и лутбоксы.

Стек: **Python 3.12 · aiogram 3 · PostgreSQL · SQLAlchemy 2 (async) · Alembic · APScheduler · edge-tts**.
Опционально — **Claude API** для умной проверки письменных ответов.

## Что умеет

| Раздел | Что внутри |
|---|---|
| ⚡ 5-минутка | Микс из 10 заданий: слова, грамматика, идиомы/сленг. Уложился в 5 минут — бонус x2 |
| 📚 Слова | ~340 слов A2–B1 по темам (быт, работа, покупки, здоровье, город, путешествия, сериалы, неправильные глаголы…), новые выдаются вперемешку по темам, 7 в день, повторение по SM-2 (как в Anki), квиз из 4 вариантов, озвучка, свои слова через `/add`, импорт из Anki через `/anki` |
| 📖 Грамматика | 16 уроков от слабых мест из теста (формы глагола, if-предложения, артикли/предлоги) до B1. Теория + практика, ошибки попадают в «Работу над ошибками» |
| 🎧 Аудирование | 10 озвученных историй с вопросами (с медленной версией), диктант из твоих же слов, подборка видео под уровень |
| 🎯 Квесты | Каждый день 3 задания (🟢🟡🔴): «посмотри серию с англ. субтитрами и выпиши 10 слов», голосовые, мини-сочинения. Один раз в день можно заменить кубиком |
| 🧪 Проверка | Еженедельная контрольная: грамматика по слабым местам + слова, разбивка по темам и динамика |
| 👤 Профиль | Уровень, XP, стрик и заморозки, график недели, ачивки, «Путь к B1» в процентах |
| ⏰ Напоминания | В выбранное время, «спасение стрика» вечером, воскресная проверка |

## Быстрый старт (Docker)

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Скопируй настройки и впиши токен:
   ```bash
   cp .env.example .env
   # открой .env и замени BOT_TOKEN
   ```
3. Запусти:
   ```bash
   docker compose up -d --build
   docker compose logs -f bot
   ```
   Миграции базы применяются автоматически при старте контейнера.
4. Напиши боту `/start`.

## Самый простой запуск на Mac (без Docker и без PostgreSQL)

Для одного пользователя хватит SQLite: база — это просто файл `bot.sqlite3` в папке проекта.

```bash
# 1. Python 3.10+ (встроенный в macOS python3 обычно 3.9 — он не подойдёт)
brew install python@3.12        # если нет Homebrew: https://brew.sh

# 2. Код и зависимости
git clone https://github.com/ghosthole/learnenglish-bot.git
cd learnenglish-bot
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Настройки
cp .env.example .env
# в .env: впиши BOT_TOKEN и замени DATABASE_URL на
# DATABASE_URL=sqlite+aiosqlite:///bot.sqlite3

# 4. Создать базу и запустить
alembic upgrade head
python -m bot
```

Бот работает, пока открыт терминал. Остановить — `Ctrl+C`, запустить снова — `source .venv/bin/activate && python -m bot`.

## Запуск без Docker (PostgreSQL)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt

# PostgreSQL должен быть запущен; в .env укажи
# DATABASE_URL=postgresql+asyncpg://bot:bot@localhost:5432/learnenglish
alembic upgrade head
python -m bot
```

## Настройки (.env)

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | Токен бота (обязательно) |
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `DEFAULT_TIMEZONE` | Часовой пояс по умолчанию (меняется в боте: ⚙️ Настройки) |
| `ANTHROPIC_API_KEY` | Необязательно. Включает умную проверку: Claude засчитывает другие правильные варианты перевода и объясняет ошибки, а также разбирает сочинения из квестов |
| `ANTHROPIC_MODEL`, `ANTHROPIC_EFFORT` | Модель и глубина размышлений. По умолчанию `claude-opus-5-5` и `low`. Можно поставить модель дешевле, например `claude-haiku-5-5` |
| `TTS_VOICE` | Голос озвучки по умолчанию |
| `TTS_PROXY` | Прокси для озвучки, если сервис Microsoft недоступен напрямую |

Озвучка работает через [edge-tts](https://github.com/rany2/edge-tts) (бесплатно, без ключей). Если озвучка недоступна,
бот покажет текст вместо аудио, и задание всё равно можно пройти.

```

    quests.py          квесты
    fun.py             идиомы/факты/сленг, тексты напоминаний
  handlers/            обработчики разделов (start, words, grammar, listening, quests, sprint, profile, check)
  services/

    checker.py         проверка письменных ответов (нормализация сокращений и пунктуации)

    practice.py        что уже показывали — чтобы задания не повторялись подряд
```

## Как добавить контент

- **Слова** — допиши строку в нужный список в `bot/content/words.py`. При следующем запуске бот сам добавит новые слова в базу. Как часто давать слова каждой темы, задаёт `TOPIC_WEIGHTS` в `bot/services/words.py`.
- **Слова из Anki** — в Anki: Файл → Экспорт → «Anki Deck Package (.apkg)», и пришли файл боту (или `/anki`). Прогресс повторений переносится.
- **Предложение на перевод** — допиши `tr(...)` в конец списка нужного урока в `bot/content/sentences.py`. Варианты ответа — шаблоном: `"I {like|love} {cooking|to cook}."`.
- **Урок грамматики** — добавь `Lesson(...)` в `LESSONS` в `bot/content/grammar.py`. `id` урока после запуска не меняй: по нему хранится прогресс.
- **Квест** — добавь `Quest(...)` в `bot/content/quests.py` (тип сдачи: `words`, `text`, `voice`, `any`).
- **История для аудирования** — добавь `Story(...)` в `bot/content/listening.py`.

## Изменение базы данных

Поменял модель в `bot/db/models.py` → создай миграцию и примени её:

```bash
alembic revision --autogenerate -m "что поменял"
alembic upgrade head
```

## Тесты

```bash
pytest                      # SQLite в памяти, ничего настраивать не нужно
TEST_DATABASE_URL=postgresql+asyncpg://bot:bot@localhost/learnenglish_test pytest   # на PostgreSQL
```

Сквозные тесты гоняют настоящий диспетчер aiogram: «нажимают» кнопки и проверяют ответы бота, без обращения к Telegram.
